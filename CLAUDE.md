# Проект: «Нихао Андрей» — фан-самоучитель китайского в стиле MechWarrior 5

Одна страница `index.html` (~38 КБ): весь HTML, CSS и JS внутри, без сборки и зависимостей.
Git: `lowsun-cyber/fun-china` (публичный), публикация — GitHub Pages: https://lowsun-cyber.github.io/fun-china/ (из `main`).

## Содержание
Разделы: четыре тона, пиньинь (латиница ≠ русские звуки), первые фразы, числа 1–10, первые иероглифы,
грамматика (4 правила), «брифинг перед вылетом». Озвучка — голос устройства (`speechSynthesis`, `zh-CN`),
при отсутствии — сообщение «Браузер не умеет озвучивать». Прогресс — `localStorage` (ключ `nihao_bills`).

## Правила
- Интерфейс по-русски, китайский — иероглифы + пиньинь с тонами; точность тонов и иероглифов важнее оформления.
- Стиль MechWarrior 5 (меха, брифинг, HUD) — это бренд проекта; шрифты Exo 2 и Russo One (Google Fonts).
- Оставаться одним файлом без сборки, пока владелец не решит иначе.
- Общие правила и материалы — `../CLAUDE.md`, `../_shared/`.
